06 // FAQ

Quick answers before we work together.

What kind of game projects can you work on?

Unity-based Android projects across casual, puzzle, simulation, racing, stunt and shooting genres — including new builds, feature updates and inherited codebases.

Are you hands-on or mainly a team lead?

Both. My current role includes team leadership, but I stay hands-on with Unity, C#, debugging, optimization, SDK integrations and release-related engineering.

Can you improve an existing game instead of building from scratch?

Yes. I can work on performance issues, crashes, SDK updates, UI/gameplay changes, monetization integrations, Firebase setup and store-readiness for an existing Unity project.

Which monetization and analytics tools have you worked with?

AdMob, AppLovin MAX and TopOn for ads/mediation, plus Firebase Analytics, Crashlytics and Remote Config for measurement, stability and live tuning.

Do you have experience beyond Google Play?

Yes. My publishing experience also includes Transsion, XGames, XPlay, Vivo Store and Mi Store.

What's the best way to discuss a collaboration?

Send a short email with the game type, current stage, platform, key problem and expected scope. I can then quickly identify where I can contribute most effectively.
